Check a Tzun evidence record yourself

Drop a proof bundle and get the report of tzun-verify, the standalone verifier, compiled to WebAssembly. It runs in this browser: the bundle is read here and never uploaded, and the one request this page can make on its own is to the Ethereum node you name in step 4.
